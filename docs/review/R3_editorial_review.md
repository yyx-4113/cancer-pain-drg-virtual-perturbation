## 三、本轮修复后**结论方向改变**的问题（须在稿件中如实反映）

1. **自环 bug + 单侧 p 值 bug** 修复后，D7 的主导信号从"神经元离子通道模块"变为**I 型干扰素 / 抗原呈递 / 补体**程序（CTRL interferon mean t = +24.92，为全研究最强信号）。
2. **靶点基因被网络丢掉**的 bug 修复后，各模块基因数大幅回升（阿片受体 2/4→4/4、Na⁺ 2/5→5/5、GABA 1/5→3/5），模块层面统计量随之改变；"5 个模块被静默丢弃"不再发生。
3. 阴性对照模块同样产生 reversal，且神经元靶点模块的 mean t（−5.71 ~ −3.51）与泛神经元（−5.20）、髓鞘（−4.10）**完全重合**，故原"神经元模块特异性"结论**不成立**，改写为区室/组分效应。
4. 跨病因主终点**从扰动 reversal Δ 改为模块平均 logFC Δ 与标记基因 Δ**（配精确置换检验）。理由：reversal 在 264 项检验中无一通过 BH 校正（最小 q = 0.139），且 z 最大者为红细胞阴性对照（z = −5.78）；而 logFC Δ 功效充足、可解释、且结果方向明确。扰动层保留为**校准性次要分析**。
5. 跨病因比较同时给出 **D14 与 D7** 两个版本，不再只用一个时间点。

## 四、最终稿件的核心结论（v0.3 / final）

**正性发现（有充分证据支持）**
- 骨癌痛 DRG 转录重编程呈时相性：D1 = 0、D7 = 4600、D14 = 235 个基因 q<0.05（肌肉校正后）。
- D7 的主导程序是 **I 型干扰素**（mean t = +24.92，q = 6.8e−5）+ 髓系浸润（Cd68 +2.86、Aif1 +2.18）+ 卫星胶质活化（Gfap +1.33）。
- 跨病因**方向性分歧**：髓系标志在骨癌痛↑、紫杉醇 CIPN↓（Cd68 Δ = +3.42、Aif1 Δ = +3.08，q = 0.012）；损伤相关神经肽甘丙肽相反（Gal Δ = −2.59，q = 0.012）；Ccl2 Δ = +1.39、Il1b Δ = +1.23。
- 敏感性网格 75 个设置：发现集排序 Spearman 最小 0.959、中位 0.988，top-5 重合 5/5；跨病因 Δ 最小 0.989。结论不依赖调参。

**诚实的阴性/校准结论**
- 神经元靶点模块的下调与泛神经元、髓鞘阴性对照**无法区分** → 区室/组分效应，不是 5 个独立机制。
- 网络传播与可加基线 Spearman = 0.991（发现集）/ 0.929（跨研究基因空间）→ 图几乎不增加排序信息，呼应 2025 Nat Methods 基准。
- 扰动 Δ 在 264 项检验中无一通过 BH（最小 q = 0.139）；红细胞阴性对照 z 最大 → 该评分主要追踪组成差异而非靶点药理。
- 红细胞阴性对照在两个数据集间 ΔlogFC = −2.48（q = 0.007），直接量化了两批 DRG 标本的血液含量差异——这是神经元模块 Δ 的混杂来源。
- 单个污染样本（GSM4506604，肌源性 FPKM 6.26%）使 D7 的 DE 数从 4600 降至 3041（Jaccard 0.584），已披露。
